Installation#

Requirements#

  • Python 3.10 or higher

  • NumPy

  • pandas

  • xarray

  • scipy

  • joblib

From PyPI#

pip install fips

Optional extras#

# Atmospheric flux inversion (STILT transport, cartopy plotting)
pip install "fips[flux]"

Development Installation#

git clone https://github.com/jmineau/fips.git
cd fips
uv sync                    # fips, its flux extra, and the dev tools
uv run pre-commit install
uv run just quality-check

Building the docs also needs Pandoc. See CONTRIBUTING.md for the full workflow.
