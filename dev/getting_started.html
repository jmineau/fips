Getting Started#

fips solves the standard Bayesian linear inverse problem:

\[\hat{x} = x_0 + K(z - Hx_0), \qquad \hat{S} = S_0 - K H S_0\]

where \(x_0\) is the prior state, \(z\) the observations, \(H\) the forward (Jacobian) operator, \(S_0\) the prior-error covariance, and \(S_z\) the observation-error covariance. The Kalman gain is

\[K = S_0 H^T (H S_0 H^T + S_z)^{-1}.\]

Tip

See Terminology & Notation for a complete guide to mathematical notation and abbreviations used throughout FIPS. Different fields use different conventions — this reference helps clarify the terminology.

The three building blocks are:

  • Block / Vector — labelled 1-D state and observation vectors

  • MatrixBlock / Matrix — labelled 2-D operators and covariances

  • InverseProblem — wires everything together and runs the estimator

Note

Plain pandas.Series and pandas.DataFrame objects are accepted everywhere. fips promotes them to Block / MatrixBlock automatically, so you can start with data you already have.

Minimal Example#

In [1]: import numpy as np

In [2]: import pandas as pd

In [3]: from fips import InverseProblem

# --- Indices ---
In [4]: state_idx = pd.Index(["s0", "s1", "s2"], name="state_id")

In [5]: obs_idx   = pd.Index(["o0", "o1"],        name="obs_id")

# --- Prior state vector ---
In [6]: prior = pd.Series([1.0, 2.0, 3.0], index=state_idx, name="state")

# --- Observations ---
In [7]: obs = pd.Series([1.8, 4.3], index=obs_idx, name="obs")

# --- Forward operator H (maps state → obs space) ---
In [8]: H = pd.DataFrame(
   ...:     [[1.0, 0.5, 0.0],
   ...:      [0.0, 0.5, 1.0]],
   ...:     index=obs_idx,
   ...:     columns=state_idx,
   ...: )
   ...: 

# --- Error covariances ---
In [9]: S_0 = pd.DataFrame(np.diag([1.0, 1.0, 1.0]), index=state_idx, columns=state_idx)

In [10]: S_z = pd.DataFrame(np.diag([0.1, 0.1]),       index=obs_idx,   columns=obs_idx)

# --- Solve ---
In [11]: problem = InverseProblem(
   ....:     obs=obs,
   ....:     prior=prior,
   ....:     forward_operator=H,
   ....:     modeldata_mismatch=S_z,
   ....:     prior_error=S_0,
   ....: )
   ....: 

In [12]: problem.solve("bayesian")
Out[12]: InverseProblem(n_obs=2, n_state=3, solved=True)

In [13]: print(problem.posterior)       # posterior state as a labelled Vector
Vector(name='posterior', shape=(3,))
block  state_id
state  s0          0.803977
       s1          2.031250
       s2          3.258523
Name: posterior, dtype: float64

In [14]: print(problem.posterior_error) # posterior error covariance as a labelled Matrix
<CovarianceMatrix : shape=(3, 3)>

Inspecting the Solution#

After calling solve(), results are available as labelled fips objects that behave like pandas Series / DataFrames:

# Posterior state and uncertainty
In [15]: x_hat = problem.posterior        # Vector  (index = state_idx)

In [16]: S_hat = problem.posterior_error  # CovarianceMatrix

# Modelled observations for prior and posterior
In [17]: y_0   = problem.prior_obs        # Vector  (index = obs_idx)

In [18]: y_hat = problem.posterior_obs    # Vector  (index = obs_idx)

In [19]: S_y0  = problem.prior_obs_error  # CovarianceMatrix: H S_0 H^T, the prior's error on y_0

# Kalman gain and averaging kernel
In [20]: K = problem.kalman_gain          # Matrix  (obs × state)

In [21]: A = problem.averaging_kernel     # Matrix  (state × state)

# Scalar diagnostics from the estimator
In [22]: est = problem.estimator

In [23]: print(f"DOFS:       {est.DOFS:.2f}")
DOFS:       1.85

In [24]: print(f"reduced χ²: {est.reduced_chi2:.3f}")
reduced χ²: 0.058

In [25]: print(f"R²:         {est.R2:.3f}")
R²:         1.000

In [26]: print(f"RMSE:       {est.RMSE:.4f}")
RMSE:       0.0229

Working with Blocks and MatrixBlocks#

Use Block and MatrixBlock explicitly when your state space is composed of named components — for example, fluxes and a per-site bias correction:

In [27]: import pandas as pd

In [28]: from fips import Block, Vector, MatrixBlock, ForwardOperator

# --- Two state components ---
In [29]: flux_idx = pd.Index(["cell_0", "cell_1"], name="cell_id")

In [30]: bias_idx = pd.Index(["site_A"],           name="site_id")

In [31]: obs_idx  = pd.Index(["o0", "o1"],         name="obs_id")

In [32]: flux_block = Block(pd.Series([1.0, 2.0], index=flux_idx, name="flux"))

In [33]: bias_block = Block(pd.Series([0.1],      index=bias_idx, name="bias"))

In [34]: prior = Vector([flux_block, bias_block], name="prior")

In [35]: print(prior)
Vector(name='prior', shape=(3,))
block  cell_id  site_id
flux   cell_0   nan        1.0
       cell_1   nan        2.0
bias   nan      site_A     0.1
Name: prior, dtype: float64

Each forward-operator sub-block names the observation block it maps to and the state block it maps from:

# --- Matching forward-operator sub-blocks ---
In [36]: H_flux = MatrixBlock(
   ....:     pd.DataFrame([[1.0, 0.5], [0.5, 1.0]], index=obs_idx, columns=flux_idx),
   ....:     row_block="obs",
   ....:     col_block="flux",
   ....: )
   ....: 

In [37]: H_bias = MatrixBlock(
   ....:     pd.DataFrame([[1.0], [1.0]], index=obs_idx, columns=bias_idx),
   ....:     row_block="obs",
   ....:     col_block="bias",
   ....: )
   ....: 

In [38]: H = ForwardOperator([H_flux, H_bias])

In [39]: print(H.to_frame())
block          flux          bias
cell_id      cell_0 cell_1    NaN
site_id         NaN    NaN site_A
block obs_id                     
obs   o0        1.0    0.5    1.0
      o1        0.5    1.0    1.0

The covariances follow the same pattern (one MatrixBlock per component, combined in a CovarianceMatrix). Then pass everything to InverseProblem as before.
